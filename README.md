# River Crossing — Web Edition

نسخة ويب مستقلة مستندة إلى موارد APK المرفق (River Crossing 1.3.1).

## التشغيل
- افتح `index.html` عبر خادم محلي أو انشر محتويات المجلد على GitHub Pages.
- لا تفتح `index.html` مباشرة عبر `file://` لأن التطبيق يقرأ `assets/game-data.json` باستخدام `fetch`.
- محلياً: من VS Code يمكن استخدام إضافة Live Server ثم اختيار **Open with Live Server**.

## المحتويات
- 21 مرحلة، مع نصوص التعليمات والحلول الأصلية المتوفرة بخمس لغات: العربية والإنجليزية والفرنسية والإسبانية والألمانية.
- صور المعاينة الأصلية للمراحل.
- ملفات الصوت الأصلية.
- حفظ المراحل المكتملة محلياً (LocalStorage).
- واجهة متجاوبة للهاتف والحاسوب ودعم التثبيت كـ PWA.
- منطق عبور تفاعلي، سعة قارب، اختيار الركاب، التحقق من عدد من قواعد المراحل، وحالات خاصة لبعض الألغاز.

## ملاحظات المطابقة
هذا إعادة تنفيذ ويب وليس نقلًا لمحرك GameMaker الأصلي أو كود Native. يتضمن APK ملفات تنفيذية وموارد داخلية خاصة بالمحرك؛ لذلك لا يمكن ضمان تطابق الحركة والرسوم والفيزياء حرفياً. تم اعتماد نصوص التعليمات والحلول والرسوم المتاحة داخل الحزمة. بعض القيود المركبة في المراحل المتقدمة تحتاج إلى مزيد من التحقق مقارنة بالمحرك الأصلي؛ اقرأ قواعد المرحلة داخل اللعبة ولا تعتبر كل الحالات الخاصة محاكاة كاملة.

## GitHub Pages
ارفع **محتويات** هذا المجلد إلى جذر المستودع، ثم:
Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
